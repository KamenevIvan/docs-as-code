# ИИ-помощник интернет-магазина

Сервис представляет собой чат-бота определённого интернет-магазина. Он предназначен для помощи клиентам в решении различных вопросов, связанных с товарами магазина.

### Основные пользователи:
1. Покупатель
2. Администратор 

### Основные функции:
1. Ответы на вопросы о товарах;
2. Ответы на вопросы о политике магазина (возврат, доставка);
3. Помощь с выбором наиболее подходящего товара;
4. Помощь с онлайн оформлением заказа;

## Комплект документации

1. **Описание проекта** — для команды, заказчика и новых участников, чтобы понимать назначение, пользователей, границы и ценность ИИ-помощника.

2. **Требования / ТЗ** — для аналитика, разработчиков и тестировщиков, чтобы зафиксировать функции, ограничения и критерии приёмки.

3. **Архитектура системы** — для разработчиков и DevOps, чтобы видеть компоненты и связи: чат, backend, каталог товаров, оформление заказов, AI-модуль и базу данных.

4. **Документация API** — для frontend-разработчиков и интеграторов, чтобы подключать чат к сайту или приложению и обмениваться данными с магазином.

5. **Документация AI-компонента** — для ML-инженеров и разработчиков, чтобы описать LLM/модель, промпты, RAG, базу знаний, ограничения и метрики качества ответов.

6. **Руководство пользователя** — для покупателя, чтобы понять, как задавать вопросы боту, получать рекомендации и оформлять заказ.

7. **Руководство администратора / оператора** — для сотрудников магазина, чтобы управлять базой знаний, отслеживать диалоги, обрабатывать эскалации и обновлять информацию о товарах, доставке и возврате.

8. **Политика обработки данных и безопасности** — для владельца продукта, юриста и DevOps, чтобы определить правила сбора, хранения и защиты данных покупателей.
