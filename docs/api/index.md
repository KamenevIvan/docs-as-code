# API

API предоставляет доступ к функциям ИИ-помощника интернет-магазина.

## Основные операции

- `POST /question` — отправить вопрос пользователя на сервер;
- `GET /question_status/ {id}` — получить статус вопроса и, если готово, ответ;
- `GET /store_politics` — получить список политик магазина по оплате, гарантии, доставке, возврату..

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
